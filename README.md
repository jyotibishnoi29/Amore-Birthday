# For My Amore · Rajkumar

A mobile-responsive vintage scrapbook birthday website built with plain HTML, CSS and JavaScript. Ready for GitHub Pages.

## Add your photos
Put your own pictures in the `images` folder and name them:
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`
- `photo-5.jpg`
- `photo-6.jpg`

Or edit the image `src` values in `index.html` to match your own filenames. JPG is recommended. Keep personal photos in the repository only if you're comfortable with them being publicly accessible.

The photo area includes vintage decorative elements (postage stamp, pressed flower, rose, paper textures and Polaroid frames) beside your photos.

## Add your song
1. Put your MP3 file in the `audio` folder.
2. Name it `your-song.mp3`, OR change the `src` in `index.html` to your actual filename.
3. Music starts only after the visitor taps the music button because browsers generally block autoplay with sound.

## Birthday countdown
The countdown targets 5 November 2026 at 12:00 AM India Standard Time (IST). Update the `birthday` value in `script.js` if you want a different date.

## Publish on GitHub Pages
1. Create a repository (for example `amore-vintage-birthday`).
2. Upload the contents of this folder (make sure `index.html` is at the repository root).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. After publishing, the site URL will look like `https://YOUR-USERNAME.github.io/amore-vintage-birthday/`.

GitHub Pages repositories are public on the free plan. Anyone who has the link may be able to view the site and any photos/audio you upload, so avoid adding anything you want to keep private.
